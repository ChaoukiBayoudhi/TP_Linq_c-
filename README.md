# TP Linq C

## Tech stack

- C# / .NET
- Windows Forms
- Target framework: v4.6.1
- ADO.NET (SqlClient)
- LINQ

## Contents

- Forms: AddAuthorForm, AddBookForm, ListOfBooksForm, ModifyBookForm
- Classes: LibraryLinq.designer
- SQL scripts: `Author.sql`, `Book.sql`, `BookAuthors.sql`, `LibraryDB.sql`

## How to run

Open `CRUDLinqTp2019.sln` in Visual Studio (Windows) and press F5. The app connects to SQL Server: update the connection string to your own server first.
